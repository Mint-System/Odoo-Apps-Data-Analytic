# Odoo Apps: Data Analytic

Odoo modules extending the `data` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Data-Analytic.git ./addons/data_analytic
```

## Available modules

| Module | Summary |
| --- | --- |
| [jupyter_lab](jupyter_lab) |         Manage Jupyter Lab projects and access Odoo ORM from notebooks. |
